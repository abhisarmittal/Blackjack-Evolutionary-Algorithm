# Blackjack-Evolutionary-Algorithm

This is the source code directory for my final Senior Project for the completion of B.S. in Computer Science at Yale University. The project is titled "Using Evolutionary Algorithms to Approximate Optimal Blackjack Strategy" and I was advised by Professor Stephen Slade in the Department of Computer Science.

See [Project Webpage](https://zoo.cs.yale.edu/classes/cs490/24-25b/mittal.abhisar.am3678) for further details regarding the project as well as the final thesis report.

Ready for submission on May 1, 2025.
